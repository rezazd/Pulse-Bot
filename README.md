

\# 🚀 Pulse Bot - Advanced V2Ray Telegram ERP



Pulse Bot is a powerful, asynchronous Telegram bot designed to seamlessly integrate with the \*\*Marzban Panel\*\*. It automates user management, subscription sales, and monitoring.



\## ✨ Features

\- 🛒 \*\*Dynamic Shop:\*\* Sell V2Ray plans automatically.

\- 💳 \*\*Wallet System:\*\* Users can charge their wallets via bank transfer (Admin approval required).

\- 📊 \*\*Smart Monitoring:\*\* Auto-warns users at 80% data usage or 3 days before expiration.

\- ⚡ \*\*High Performance:\*\* Built with `aiogram 3.x`, `SQLAlchemy 2.0`, and `MariaDB`.

\- 🐳 \*\*Dockerized:\*\* Zero-conflict installation alongside your Marzban panel.
